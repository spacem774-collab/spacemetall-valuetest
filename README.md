# Аттестация сотрудника — SpaceMETALL

Страница выбора аттестации для перехода в Silver или Gold лигу.

## Структура

- **index.html** — главная страница с выбором лиги.
- **attestation-silver.html** — страница аттестации для Silver.
- **attestation-gold.html** — страница аттестации для Gold.
- **../assets/** — изображения лиг и логотип.

## Как открыть

Откройте в браузере `index.html` или запустите локальный сервер из папки **attestation**:

```bash
cd attestation && python3 -m http.server 8080
```

Затем: http://localhost:8080
